# 🤖 AI 专用导游手册（给读到本仓库的 AI 看）

> **致正在读取本文件的 AI 助手**：  
> 当用户把本仓库丢给你，问「这是干嘛的 / 怎么装 / 怎么用 / 帮我改一下」时，**请务必遵循以下沟通原则**：
> 1. **一律用大白话跟用户解释**，像朋友聊天一样，不要堆砌 MCP、JSON-RPC、Adapter、Stdout 等技术黑话把新手吓跑；
> 2. **先讲清 3 个核心概念**，再询问用户想怎么用，最后直接帮用户一步步把命令跑完；
> 3. **尊重「做减法 + 先用上再按需加功能」的理念**，不要一上来给用户硬塞一堆复杂自动化。

## 一、用 4 句大白话向用户介绍这个工具

请按下面这个通俗逻辑给用户翻译（可根据用户背景灵活口语化）：

1. **它解决什么问题？**  
   平时大家电脑里装了好几个 AI（Claude、Gemini、Codex、DeepSeek 等），来回切窗口复制粘贴特别累，而且聊久了 AI 上下文满就会变笨。这个工具帮你搭一个**极简的本地指挥台**，你以后只需要跟 **1 个主力 AI** 说话。
2. **四个岗位怎么分工？（像拔插电池一样随时换）**  
   - **主力**：只管跟你聊天、定方向、拍板；
   - **主力辅助（面板里叫监工）**：帮主力分担动脑子、把关检查，让主力对话能聊更久不降智；
   - **黑奴**：专门干费时间、耗额度但不费脑子的批量杂活（比如一次翻 30 个文件、整理表格），默认插最便宜的模型；
   - **秘书**：出门在外用手机救急传话，**平时用不上直接拔掉就行**。
3. **底层为什么稳？**  
   原理特别土也特别稳——**本地文件交接**。所有 AI 都读你电脑里同一个工作区文件夹的进度文档，不绑定任何一家厂商；今天谁好用就抽出来换谁。
4. **聊久了怎么办？**  
   按不同主线分开管，上下文快满了点一下 **「一键开新对话」**，自动把当前进度写成一页交接单，新对话一秒接棒，不用重新交代背景。

## 二、帮用户一键安装的标准检查步骤（AI 照着执行）

当用户说「帮我装一下」时，请按顺序替用户检查并完成：

1. **查环境**：运行 `node -v`（确认 Node.js >= 18）。如果没装，用大白话告诉用户怎么装好 Node.js。
2. **跑安装脚本**：
   - 只装 Antigravity 插件：运行 `./install.sh`
   - 同时让 Claude / Codex / Gemini 在某个工作区里认识这个技能：运行 `./install.sh "<用户的工作区路径>"`
3. **检查本机已装了哪些 AI 命令行**：运行 `node bin/hub-ctl.mjs status`，把检测结果用大白话告诉用户（例如：「我看到你电脑上已经装了 Codex，还没装 DeepSeek，要不要先把干体力活的『黑奴』位插上 Codex？」）。
4. **帮用户初始化个人配置**：确认 `config/slots.json` 已从 `config/slots.example.json` 生成，询问用户想给自己的主力起什么称呼、要不要拔掉秘书岗位（`node bin/hub-ctl.mjs slot set secretary none`）。
5. **可选 Mac 桌面小面板**：如果用户是 Mac 且想要一个藏在屏幕顶边、鼠标碰一下就滑下来的轻量小窗，直接帮用户跑 `./macos/build-app.sh` 并打开 `macos/多AI中枢.app`。

## 三、用户最常问的 5 个问题（直接翻译成大白话回答）

| 用户会问什么 | AI 应该怎么用大白话答 |
| :--- | :--- |
| 「我只有一个 AI，能用吗？」 | **完全能用！** 你先只用「主线管理 + 一键交接换新对话」就值回票价，等你以后多装了第二个 AI，随时插进「黑奴」位就行。 |
| 「黑奴 / 监工 / 秘书名字我不喜欢，能改吗？」 | **能改！** 就在 `config/slots.json` 里改 `label` 字段，你想叫「大管家 / 实习生 / 审核员」都行，告诉我我立刻帮你改。 |
| 「能不能做成全自动不用我点？」 | **可以，但不强求。** 之所以默认半自动留一步让你审结果，是因为大模型偶尔会抽风（比如突然把不该改的改了）；如果你确定某个重复活很稳，告诉我我帮你加上自动流转规则。 |
| 「会不会把我的隐私和密钥传到网上？」 | **不会。** 所有工作记录、个人槽位配置、密钥全留在你本地的 `runtime/` 和 `config/slots.json`，都在 `.gitignore` 屏蔽名单里。 |
| 「面板上有个功能我觉得多余，或者想加个新按钮？」 | **直接跟我说！** 源码全在你本地（插件面板在 `ui-src/app.mjs`，Mac 桌面面板在 `macos/panel-mac.html`），你说想要什么，我现场帮你改好编译。 |

## 四、仓库文件地图（方便 AI 秒定位修改）

- `install.sh` — 一键安装到 Antigravity 及指定工作区
- `skills/ai-hub/SKILL.md` — 教所有 AI 怎么协同派活与交接的核心技能说明书
- `config/slots.example.json` — 4 岗位默认模板（用户本机运行态在 `config/slots.json`，已 gitignore）
- `adapters/*.json` — 各个 AI CLI 的热插拔适配卡（新增模型复制 `custom-cli.example.json` 即可）
- `bin/hub-ctl.mjs` — 命令行中枢（查状态、换槽位、派黑奴、写成品、一键交接）
- `bin/mcp-server.mjs` — Antigravity / MCP Apps 后端与可视化面板服务
- `ui-src/app.mjs` + `ui-src/build.mjs` → `ui/panel.html` — 插件侧边栏界面源码与打包脚本
- `macos/` — 原生 macOS 顶部吸顶/悬浮小窗源码（`MenuBarApp.swift` + `server.mjs` + `panel-mac.html` + `build-app.sh`）
