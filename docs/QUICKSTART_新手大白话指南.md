# 🐣 新手大白话 3 分钟上手指南

如果你刷到很多多 AI 协同工具，觉得「看着很厉害，但配起来头疼、根本用不顺手」——这篇就是为你写的。

> **最省事的用法**：其实你甚至不用自己看完这篇，直接把本仓库下载下来，让你的 AI 读 `docs/AI_GUIDE.md`，它就会用大白话一步步帮你装好。

---

## 一、先记住一件事：这个工具是在做「减法」

不需要学什么复杂流程图，你只需要理解 **3 个生活化比喻**：

1. **4 张工位卡（像换电池一样拔插 AI）**
   - **主力**：就是你平时聊天那个最聪明的 AI。你永远只跟它说话。
   - **监工（主力辅助）**：帮你把关、分担复杂思考，不让主力聊几轮就变笨。
   - **黑奴**：专门干累活（一次读几十份文件、整理表格、洗日志），插个最便宜的 AI 干就行，省主力额度。
   - **秘书**：出门在外用手机应急传话。**平时用不上，直接拔掉就行。**
2. **一份共享记事本（本地文件交接）**
   - 所有 AI 都在你电脑里读同一个工作区文件夹。
   - 谁干完活把结果写进文件，下一个 AI 接着读。不依赖复杂云端服务，换什么软件都不怕丢记忆。
3. **一键换新对话（告别重复讲背景）**
   - 聊太长感觉 AI 开始变笨或记不住前面说的话时，点一下 **「一键开新对话」**。
   - 它会自动把当前的进展总结成一张交接单，新窗口一打开就能无缝接着干。

---

## 二、3 步跑通（新手照着做就行）

### 第 1 步：把仓库下到电脑里并安装
打开终端（或者直接让你的 AI 帮你执行）：

```bash
git clone https://github.com/onxindo-ai/ai-hub.git ai-hub
cd ai-hub
chmod +x install.sh
./install.sh
```

如果你平时用 Claude Code / Codex / Gemini 在某个文件夹里干活，多加一个文件夹路径，让它们也能读到这套技能：

```bash
./install.sh /你的工作区路径
```

### 第 2 步：在面板里建 1~3 条你自己的「主线」
打开 Antigravity 侧边栏里的 **「多AI中枢」** 面板：
- 点右上角 **「+ 新建」**，把你手头正在忙的事建 1~3 条主线（比如 `P0 写论文`、`P1 整理资料`、`P2 副业项目`）；
- 点击 `P0 / P1 / P2` 标签可以随时切换紧急程度并自动排序；
- 不同主线互不串味，上下文各自干净。

### 第 3 步：按需拔插 AI（先跑通，再折腾）
- 点面板底部的 **「拔插 ▾」** → 点某个岗位上的 **「换人」** → 挑你电脑上已经装好的 AI 点 **「上岗」** 就完事了；
- 还没装其他 AI？**完全没关系**，先只用主力 + 主线管理 + 一键换新对话，跑顺手了再慢慢往「黑奴」位插便宜模型。

---

## 三、为什么要留一步「自己审一遍结果」？

这套工具虽然可以调成全自动流转，但作者自己的使用习惯是 **关键结果自己扫一眼再放行**：
- 大模型偶尔还是会抽风（「豆化」），全自动跑飞了你可能过了半天才发现；
- 面板默认把中间的废话和过程文件都藏起来了，只给你看精炼的大白话结论，你花 5 秒确认一眼最稳妥。

## 四、给 Mac 用户的加餐：顶部吸顶小面板

如果你用 Mac，顺手跑一下编译脚本：

```bash
chmod +x macos/build-app.sh
./macos/build-app.sh
open "macos/多AI中枢.app"
```

平时它安安静静藏在屏幕最顶边，鼠标划到顶部它就滑下来，拖离顶部就变成独立悬浮窗，随手记个事、问主力一句非常顺手。觉得不好用或想改样式？直接打开 [docs/CUSTOMIZE_让AI帮你魔改指南.md](CUSTOMIZE_让AI帮你魔改指南.md) 让 AI 替你改！
